# ec_bridge

Dart bindings for the Rust core (`crates/ec-ffi`), generated by
[flutter_rust_bridge](https://github.com/fzyzcjy/flutter_rust_bridge). The Rust library
is compiled for each platform by [cargokit](cargokit/README) (MIT/Apache-2.0) when an app
is built, so `flutter run` in any app builds the Rust code too.

After changing `crates/ec-ffi/src/api`, regenerate the bindings:

```sh
cargo install flutter_rust_bridge_codegen --version 2.13.0 --locked
cd packages/ec_bridge && flutter_rust_bridge_codegen generate
```

Files under `lib/src/rust/` and `crates/ec-ffi/src/frb_generated.rs` are generated;
do not edit them by hand.
